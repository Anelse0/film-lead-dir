# 镜头手法一览

第 5 步写分镜时从这里选。每个镜头定四样：景别、角度、运镜、接法。

- 「现行」一栏按 `current-style.md`：默认平视、轻微手持。标"点名才用"的，用户说了才用。
- 官方列出的词可以直接写；其余术语补上作用主体和画面变化。

## 景别

| 景别 | 取景范围 | 什么时候用 |
|---|---|---|
| 大全景 | 人物在环境里很小 | 交代地点和人与环境的关系；孤立感、距离感 |
| 全景 | 从头到脚，上下留空 | 交代人物在空间里的位置和全身动作 |
| 中全景 | 大约膝盖或大腿以上 | 动作和神情都要看到 |
| 中景 | 大约腰以上 | 对白戏常用，人物和环境兼顾；进特写前的过渡 |
| 中近景 | 介于中景和近景之间 | 比近景多带一点身体动作 |
| 近景 | 大约胸以上 | 看得清表情和上身动作，又留一点距离 |
| 特写 | 一张脸 | 情绪和反应；关键时刻 |
| 大特写 | 眼睛、嘴、手指等局部 | 极小的细节 |
| 插入镜头 | 一件东西或一个细节 | 交代关键物件 |

- 官方的景别词是大全景、全景、中景、近景、特写。
- 竖屏的双人正面用中景。中近景和近景容易把画边的脸切掉。
- 少用两三秒的插入镜头。

按画面里的人物关系，四种构图：

| 构图 | 是什么 | 什么时候用 |
|---|---|---|
| 单人镜头 | 画面里只有一个人 | 把注意力给一个人的话或反应 |
| 双人镜头 | 两人同框 | 交代两人的关系；远近本身就在说明关系 |
| 过肩镜头 | 越过一人的肩拍另一人 | 对话时保住两人的空间关系；让视线有落点 |
| 主观镜头 | 从人物眼睛的位置看出去 | 让观众看见他看见的东西 |

## 角度

| 角度 | 效果 | 现行 |
|---|---|---|
| 平视，与眼睛同高 | 与角色最直接的连接 | 默认 |
| 高角度 | 削弱角色，显得弱 | 全条最多一处轻俯拍 |
| 低角度 | 增强角色的力量感 | 点名才用 |
| 顶视 | 脆弱、渺小，或全知的旁观 | 点名才用 |
| 倾斜（荷兰角） | 加重紧张 | 点名才用 |
| 正脸、3/4 侧脸、正侧面 | 机位越贴近视线，观众越贴近角色；正侧面是旁观的角度 | 以正脸和 3/4 侧脸为主 |

机位的高度和角度写在机位表的「高度」栏，一个机位写一次。

## 焦段

| 焦段 | 画面的样子 | 什么时候用 |
|---|---|---|
| 广角 | 空间显得大，近处的东西被放大；贴近脸会变形 | 全景，交代空间 |
| 中焦 | 接近人眼平常看到的样子 | 中景，双人 |
| 中长焦 | 背景被拉近、虚得更多，脸不变形 | 近景，单人 |
| 长焦 | 背景压得很扁，像从远处看过去 | 特写；旁观、偷看的感觉 |

- 写在机位表的「焦段」栏。Prompt 里写看得见的结果更明确：背景虚不虚、近不近。
- 近景和特写用中长焦，不用广角贴近脸。

## 运镜

每个运镜写清三样：围绕谁、起点、终点。

| 运镜 | 是什么 | 什么时候用 | 怎么写 | 现行 |
|---|---|---|---|---|
| 手持 | 端着拍，画面轻微晃动 | 临场感、能量 | 官方词。写跟拍对象和晃动程度 | 默认，轻微 |
| 固定 | 机位不动，人物在画面里动 | 对白和表演，不分散注意力 | 写「镜头固定」 | 点名才用 |
| 摇 | 机位不动，水平转向 | 跟随人物；揭示新信息 | 官方词「摇」 | |
| 甩 | 很快的摇 | 加能量；不切就把两个人连起来 | 写方向和速度 | |
| 上摇、下摇 | 机位不动，垂直转向 | 交代尺度和高低关系 | 官方词「上摇」 | |
| 推 | 机位朝人物靠近 | 危机或醒悟的一刻；紧张或亲近 | 官方词「推」，如「缓慢推近」 | |
| 拉 | 机位远离人物 | 揭示环境；孤立、抽离 | 官方词「拉」「后拉」 | |
| 变焦 | 机位不动，改变焦距 | 把注意力集中到一处 | 写清画面里什么被放大 | |
| 希区柯克变焦 | 推拉和变焦反向同时做，主体大小不变，背景变形 | 人物的心理冲击 | 官方热门运镜。写主体保持的大小、背景被拉近还是推远 | |
| 跟、移 | 机位随人物穿过空间；横移是平行于人物移动 | 跟随动作；边走边谈 | 官方词「跟」「移」，如「镜头与人物同速水平移动」 | |
| 环绕 | 机位绕着主体转 | 动感、张力 | 官方词「环绕」。写环绕方向 | |
| 升降 | 机位升高或降低 | 从高处落进一场戏，或拉高收尾 | 写起点高度和终点构图 | |
| 稳定器长跟拍 | 稳定器跟着人物连续穿行 | 长时间的流畅跟随 | 官方热门运镜「一镜到底」。写连续经过的主体、空间和事件顺序 | |
| 航拍 | 无人机的俯瞰 | 交代环境；跟拍车辆 | 官方热门运镜。写俯视高度、移动方向、环境范围 | |
| 移焦 | 焦点从一处转到另一处 | 不动机位也不切，把注意力转给另一处 | 写焦点从哪里平滑转到哪里 | |

## 调度与长镜头

| 手法 | 是什么 | 什么时候用 |
|---|---|---|
| 一镜到底 | 一个连续镜头拍完一段戏，中途靠走位和运镜换出几个构图 | 想憋住张力，或带观众跟着人物进入一个空间 |
| 走位换景别 | 人物走近或走远，景别随之改变 | 不切也能从全景到近景 |
| 前后景分层 | 前景和背景同时有戏 | 一个画面交代两件事，画面有纵深 |
| 用距离说关系 | 两人站得远还是近 | 不靠台词交代两人的关系 |

单条最长 30 秒，一镜到底只能在一条 clip 之内做。15 秒以上的长走位先用单个镜头试。

## 镜头之间的接法

| 接法 | 是什么 | 什么时候用 | 怎么写 |
|---|---|---|---|
| 开场 | 一条 clip 的第一镜，前面没有可接的 | 每条的第一镜 | 不写接法 |
| 硬切 | 直接切到下一个镜头 | 默认 | 在镜头行开头写「硬切」 |
| 动作接动作 | 上一镜给动作的开头，下一镜接动作的后段 | 让切点不显眼 | 上一镜以动作收，下一镜以同一动作起 |
| 接上一条末帧 | 下一条 clip 的第一镜从上一条成片的最后一帧接着演 | 同一机位延续 | 末帧当参考图，只管第一镜的开头；接着动，不重演 |
| 甩镜转场 | 快速横移，借遮挡切到下一处 | 加速，连接两处 | 写方向、速度、什么东西完成整屏遮挡时切换 |
| 声音先入或后出 | 下一镜的声音先进，或上一镜的声音拖后 | 对白戏，让切点更顺 | 在剪辑软件里做，不写进 Prompt |

分镜表的「接法」栏从这张表的前五种里选。时间段是事件的时间预算，不是精确的剪辑点，精确切点留给剪辑软件。

## 出处

- 景别、运镜的定义和用途：Jay Holben，《American Cinematographer》Shot Craft 专栏（Tools for Camera Movement、Where Do You Put the Camera?）；StudioBinder 的景别表和运镜指南（教学网站，不是一手资料）。
- 变焦和推的区别：Roger Deakins 的论坛回帖。
- 调度四样：No Film School 对 Spielberg 调度方式的归纳，二手分析。
- 「怎么写」一栏：Seedance 2.5 官方指南，见 `seedance-2.5.md`。
