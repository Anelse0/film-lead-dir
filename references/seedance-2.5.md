# Seedance 2.5 官方要点

只留参考生视频用得上的。写 Prompt 拿不准官方怎么说时查。这里没写的能力和参数，不当成官方说过的；要试没验证过的写法，在参数段的「未验证」里列出来。

来源标记：`[指南]` 火山方舟《Doubao Seedance 2.5 提示词指南》（2026-11-03 版）；`[撰写指南]` 官方飞书文档《Seedance 2.5 提示词撰写指南》；`[sd25-pe]` 官方 skill 0.1.1；`[自定]` 官方没说、本 skill 自己定的。

## 边界

| 项 | 官方 | 来源 |
|---|---|---|
| 单条时长 | 最长 30 秒 | 指南 |
| 时间 | 响应整数秒的时间段；时间段是事件的预算，不是精确剪辑点，动作可能提前或延后 | 指南、撰写指南 |
| 素材上限 | 图 30 张、视频 10 段、音频 10 段，合计 50 个 | 指南 |
| 主体图 | 1–8 个效果较好，9–12 个稳定性下降 | 指南 |
| 多视图 | 5 个主体以内单视图、多视图都行；超过 5 个用单视图 | 指南 |
| 画幅 | 宽高比 0.4 到 2.5 之间任意 | 指南 |
| 语言 | 原生支持十多种 | 指南 |
| 生成参数 | 画幅、总时长、分辨率在页面或接口里设，不写进 Prompt 正文 | sd25-pe |
| 任务拆分 | 一次承担的要求太多效果不稳，拆成几个简单任务 | 指南 |

## 结构

官方四段和本 skill 六段的对应：

| 官方 | 本 skill |
|---|---|
| 素材指代：每份素材按上传顺序写明用途 | 【素材绑定】 |
| 一句话概述：主体、地点、事件、风格 | 【总述】 |
| 具体情节：时间段或「镜头 N」，逐段写画面、运镜、动作、台词、音效 | 【起始状态】【分镜时间线】 |
| 结尾：贯穿始终的机位、环境、声音、氛围 | 【画面基调】【贯穿要求】 |

- 段名官方不固定，四个带台词的例子用了四套。六段是本 skill 的骨架 `[自定]`。
- 官方没有字数上限。15000 字符是用户定的 `[自定]`。

## 素材

- 每份素材用文字绑定，不靠图上的字认人 `[指南]`。
- 逐份写它提供什么；图里的人物、背景、构图容易被带进成片时，写不采用什么 `[撰写指南]`。
- 素材够准时只指代，不复述图里的画面 `[指南]`。
- 人物按首次出场顺序上传，编号同步，否则先出场的人会被别的角色顶替 `[指南]`。
- 多人：逐一命名并绑定；加一句外貌、服装、动作、站位和台词不互相交换 `[撰写指南]`。
- 参考图分辨率不超过输出分辨率，否则密纹理处出指纹状纹理 `[指南]`。
- 画面里要准确的文字：做成图当参考，或后期加 `[指南]`。

## 时间和镜头

- 一段时间里内容少，模型自由发挥；内容多，过度剪切或漏剧情 `[指南]`。每个阶段只安排一个主要变化，并写清结束时看得到的状态 `[撰写指南]`。
- 不用时间控制频次（「一秒摇头三次」）`[指南]`。
- 可以直接写的词 `[撰写指南]`：
  - 景别：大全景、全景、中景、近景、特写。
  - 运镜：推、拉、摇、移、跟、环绕、俯冲、后拉、上摇、手持晃动。
  - 机位：低角度、俯视、第一人称。
- 热门运镜（一镜到底、希区柯克变焦、航拍、手持镜头等）可以直接用；画面里有多个主体时写围绕谁、从哪开始、到哪结束。手持写跟拍对象和晃动程度 `[撰写指南]`。
- 小众术语：术语 + 作用主体 + 画面变化 + 前后景关系 + 方向或速度 `[撰写指南]`。
- 每个运镜都写围绕谁、起点、终点，是用户的规矩 `[自定]`；官方只对多主体的热门运镜这样要求。
- 站位围绕固定的东西写（沙发、桌子、门），不只写画面左右 `[sd25-pe]`。

## 动作、表情、情绪

- 动作先概括，只给少数有记忆点的动作写细节，不重复写同一个动作 `[指南]`。
- 表情写描述性的句子，少用成语 `[指南]`。
- 只写情绪词，模型懂方向，但表演自由发挥。要稳定就写眼神、眉头、嘴角、呼吸、视线、手部动作。一次转折选 2 到 4 个最明确的表现；多次转折才按触发事件分阶段 `[撰写指南]`。
- 情绪的默认写法四句 `[撰写指南]`：整体情绪从哪转到哪；触发事件后先出现什么即时反应；随后哪个部位逐渐怎么变；最终以什么外在表现表达目标情绪。
- 官方例子的做法 `[指南]`：先写触发再写反应；多个动作写明先后；听的人也写反应；全局一句「表演细腻真实，不过度夸张」。
- 有触发的反应，先让观众看清触发的原因，再给反应 `[sd25-pe]`。
- 强烈情绪词（狂热、极度震惊）会让眼睛发光。办法：换成常规词；写明人物是正常人眼 `[指南]`。

## 台词

- 特殊字符（可选）：台词用花括号，音效用尖括号，音乐用圆括号，字幕用方头括号 `[撰写指南]`。
- 台词不是中文时在前面写明语言。公式：台词语言 + 地区变体或口音 + 表达方式 + 说话人 + {台词}。例子里表达方式只有一两个词 `[撰写指南]`。
- 台词后面不复述台词里的词，也不追加语气、表情、动作的描述，否则容易出字幕 `[指南]`。
- 说法写在台词前面，例：「用平静但略微发紧的声音说：{…}」`[sd25-pe]`。
- 多人对话逐段写明谁说，其余人自然闭口聆听 `[sd25-pe]`；例子里是全局一句「全程自然闭口，只用眼神和表情回应」`[指南]`。
- 全局约束的例子：严格按台词生成音频，不增不减；排除错误人物发声、多人同时说话、重复台词、漏词 `[指南]`。
- 口音不擅自加，用户说了才写 `[sd25-pe]`。
- 官方没有的 `[自定]`：语速（默认英文 3.5 词/秒、中文 4 字/秒）；音量、停顿、重音、句尾这四项说法；画外台词写声音从画哪一侧传来。

## 声音

- 负向约束只明确支持两样：字幕、音频（音效、背景音乐、对白可以分开管）`[指南]`。
- 写了不要背景音乐仍可能出音乐。办法：一次列全音乐的各种说法；开头和结尾各写一遍 `[指南]`。
- 水、波浪、回音这类词容易带出水泡声、回音和啸叫 `[指南]`。
- 音效用尖括号写具体的声音 `[指南]`。

## 画面和光

- 官方没有专门规则，只有例子：按参考图的色温、光影、亮度；主体清晰、背景自然虚化；光写颜色、方向、落在哪 `[指南]` `[撰写指南]`。
- 光圈、焦距可以写，但写看得见的结果更明确 `[撰写指南]`。
- 没有逐镜写脸光的例子，也没有人物光的禁忌。人物光的写法全在 `current-style.md` `[自定]`。
- 不自动加用户没要求的画质包和通用负向约束 `[sd25-pe]`。

## 提交前官方的六问

`[撰写指南]`

1. 主体和主要事件说清了吗？
2. 每份素材采用什么、不采用什么？
3. 人物逐一命名并绑定了吗？
4. 每个阶段只有一个主要变化，并写清结束状态了吗？
5. 人数、服装、道具归属、空间关系稳定吗？
6. 抽象情绪和摄影术语都对应到看得见、听得见的表现了吗？

## 不用的

编辑、延长、首尾帧、关键帧、宫格、白模、动作和运镜的参考视频、无缝转场、文生视频。官方有，本 skill 不做。
