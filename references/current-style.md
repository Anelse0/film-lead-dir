# 现行写法

固定要求都在这里。每场、每条都照它写，不等用户再说一遍。`check.py` 读文末的禁写词表。

- **听谁的**：对话里用户最新说的 > 项目的 `导演偏好.md` > 本文件 > 其余。
- **怎么改**：每场定版后，把用户新说的固定要求列成候选，用户点头才写进来，文末记一行。
- 括号里的 `#数字` 是成片证据号，细节在 `phrase-ledger.md`。

## 人物光

- 【画面基调】里写一次：按这场的场景图，有哪几盏灯、各在画左还是画右、谁用哪盏做主光。每场对着图核，不照搬别的场。
- 主光是图里的一盏灯，大而近，从人物侧前方照来，灯头只比眼睛高一点。图里灯架得高，也这样写。
- 人物把脸微微转向自己的主光；远离镜头的半边脸较亮，靠近镜头的半边脸较暗；光比约 2:1，暗面保留细节。
- 鼻影和下颌影落在自然的位置，照出颧骨、鼻梁和下颌线；光线柔和，阴影边缘过渡平缓，皮肤质感干净。
- 人物走到别处，主光跟着换，写清换成哪盏。转头离开主光时，写光落到哪半边脸。
- 人不在灯旁边时，主光写成图里那几盏灯照过来的光：离得远、弱一档。不凭空加灯。
- 一条里分区写光时加一句：全条同一种灯光、同一个颜色，暗的地方只是更暗，不变冷、不发绿（#55、#56）。
- 双人镜每人单独一句。

三处的句式。例子里的人名和灯是示意，写的时候换成这一场的：

**总句**，写在【画面基调】里，一场一次：

```
人物光：Theo 的主光是画右那两根竖着的长条灯，Rhett 的主光是画左那盏八角柔光箱。主光大而近，从人物侧前方照来，灯头只比眼睛高一点。人物把脸微微转向自己的主光，远离镜头的半边脸较亮，靠近镜头的半边脸较暗，光比约 2:1，暗面保留细节。鼻影和下颌影落在自然的位置，照出颧骨、鼻梁和下颌线。光线柔和，阴影边缘过渡平缓，皮肤质感干净。
```

**每镜的「光：」**，每张脸一句。同一机位、人没动，写「同镜头 N」：

```
光：Theo 的主光是画右那两根竖着的长条灯，大而近，从他的侧前方照过来，正是他脸微微转向的那一边；他脸上远离镜头的那半边较亮，靠近镜头的那半边较暗；鼻影和下颌影落在自然的位置，照出颧骨、鼻梁和下颌线；光线柔和，阴影边缘过渡平缓，皮肤质感干净；亮暗两侧光比约 2:1，暗面保留细节。
```

**短句**，写在【贯穿要求】里：

```
人物光：每张脸的主光都是图里的灯，从人物侧前方来；人物把脸微微转向自己的主光，远离镜头的半边脸较亮；光线柔和，暗面保留细节。
```

亮的是哪半边，照 `check.py dock3` 按俯视图算出来的写。算出来是靠近镜头的半边，先改机位或人物看的方向；改不了就照实写。

## 画面基调

- 写实真人实拍质感。
- 布局、陈设、灯的位置、影调、色彩按场景图；只借位置，不照它的构图。只写图里有的元素。
- 一条绑两张以上场景图时，几张图的色调要一致。不一致先告诉用户（#54：多绑一张偏暖的图，整片偏黄）。
- 用一句写清人物身后具体是什么，例：「人物身后是一块浅米灰色的幕布，被灯光照亮。」人物比背景略暖。
- 默认中等景深，主体清楚，背景自然虚化；肤色自然，皮肤是真实的质感，画面清晰。

## 机位和运镜

- 机位和人物眼睛同高，镜头水平，平视；以正脸、3/4 侧脸为主；近景用中长焦，不用广角贴近脸。
- 全条最多一处轻俯拍。低角度、顶视、倾斜、固定机位，用户点名才用。
- 默认轻微手持，每镜写跟谁、晃动很小。推、拉、摇写围绕谁、起点、终点，速度正常。
- 人物看对方，不看镜头。要让视线有落点，让对方的肩或后脑进前景。
- 竖屏的双人正面用中景，两张脸都完整在画里；要看清一个人的表情用单人镜。景别照常推进，靠单人镜、过肩、换角度来走。
- 不切碎：少用两三秒的插镜，反应和动作放进较长的镜头里做（#51）。

## 声音

- 只写具体的、指得出来源的动作声：皮沙发吱一声、布料摩擦、笔在纸上划、脚步、水瓶拿起来。
- 人声分远近：近处的干净、贴耳；远一点的带空间感；画外的写从画哪一侧传来。镜头换到远处，人声跟着变远。
- 每人的音色写一次：年龄感、男声女声、音高（偏低、中低音）、平常说话的样子。口音用户说了才写。
- 音色是这个人固定的声音，各场、各条原样抄。这一句怎么说（随意、认真、压低）是说话方式，跟着台词的语境变，写在每句的「台词怎么说」里，不写进音色。两样不要混。
- 一条里有两个以上相近的声音（比如几个男声），在【贯穿要求】里写清怎么分：谁更低、谁更厚、谁带口音。每句台词前写明是谁说的。
- 无音乐首尾各写一遍：【总述】里一句「没有音乐」；【贯穿要求】里把说法列全：「不要音乐、背景音乐、BGM、配乐、器乐、旋律与铺底音」。
- 写「只生成台词和写到的动作声；除了写出的 N 句台词，没有人说别的话」。不要字幕。

## 方位

- 一律画左、画右，同时写挨着哪个固定的东西（沙发扶手、门、桌子）。
- 不写人物或东西自己的左右（"他的右手""门左侧的墙板"）。指手写「靠扶手的那只手（画左那只）」（#8、#12）。
- 场景图的方位也换成画左、画右，写一句「图里的画左、画右和镜头 N 的一致」；反打镜单独写自己的画左、画右。

## 表演上限

- 情绪不设限：高兴、激动都可以是这一拍的情绪。写进 Prompt 时不拿情绪词当表演：情绪词后面跟两到四个具体的表现，上限写成具体的样子。只写情绪词，模型会自己演大（#48）。拿不准时，方向词用松快、放松这类状态词更稳。
- 一次转折写两到四个表现，写清哪个部位先动。
- 眉毛一挑、吸气、呼气、嘴角收这类小神态可以用，写的时候带上幅度：很轻，一下就回来。模型容易把它们演大。
- 笑：嘴角往上扬，眼睛跟着笑，嘴唇自然合着。不写「合着嘴的笑」，成片像害羞（#52）。
- 上限写成具体的样子，在【贯穿要求】里写一次。不靠否定句定上限（#48、#50）。
- 人物默认放松自然，肩膀打开，头抬着。剧本里的姿态词不照抄：先想它要表达什么，再用放松的样子拍。
- 呼吸只写看得见、不出声的：胸口随呼吸轻轻起伏。
- 表情跨镜接着走，不在切镜时换一张脸。低下来的一拍写「淡下去一点，脸是松的」，不写成突然严肃。
- 群体的笑和反应也写上限：几个人、低低的、几下。
- 动作正常速度，不做慢动作。

## 禁写词

脚本按类读这张表。方案的格子和 Prompt 里一个都不能有。用户点名要用某个词时，在方案开头的「放行」写上词和用户原话。

- 光：顶光、从上往下照、亮点、亮边、勾边、轮廓光、眼神光、眼睛里有亮光、眼睛里的亮光、分得开、不补光
- 背景：背景比人物暗、略冷、暗的棚、黑色幕布、不交代环境
- 声音：底噪、环境声、棚里的声音、空调低鸣、远处低声说话
- 表演：露齿、咧嘴、抿嘴、笑出声、耸肩、长出一口气、大呼一口气、瞪大、张大嘴
- 方位：东边、西边、南边、北边、东侧、西侧、南侧、北侧、东面、西面、南面、北面、东南、东北、西南、西北、朝东、朝西、朝南、朝北

## 项目的导演偏好

- 项目里有 `导演偏好.md` 时先读它。同一件事它和本文件说法不同，按它的。
- 只属于某个项目的要求写在那里，不写进本文件：某个角色的脸怎么写、口音、场边的人怎么安排、全集的镜头计划。
- 它也可以有「禁写词」一节，同名的类盖过这里的同名类。
