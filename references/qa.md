# QA 八道

每版 Prompt 交给用户之前做完。用户看到的是审过的 Prompt。

## 怎么做

1. 跑 `python3 scripts/check.py prompt <Prompt>`。脚本管的项要全过，并打印第 7 道要抄的那句数字。
2. 八道逐道过。发现问题就改 Prompt；问题在方案就回方案改，再重编那一镜。改完这一道重查。
3. 每道在场记录的「QA」里记一行。
4. 跑 `python3 scripts/check.py qa <Prompt>`，查八道都有结论、数字对得上。

## 八道

| 道 | 查什么 | 谁查 |
|---|---|---|
| 1 台词 | 逐字、顺序、说话人；每句在哪一镜；说话人在画里，还是有意放画外 | 脚本 + agent |
| 2 说法和声音 | 说法写在台词前、只写一两项、没有"快"；台词后面没有回头提台词；声音都是具体的动作声；无音乐首尾各一遍；"除了写出的 N 句"的 N 对 | 脚本 + agent |
| 3 空间 | 每镜的画左画右、挨着什么、主光是哪盏，和站位表、俯视图、脚本算的一致 | 脚本 + agent |
| 4 动作 | 每个动作在这个位置做得出来、两只手拿得下、在这个景别里看得见；一镜里的事装得下 | agent |
| 5 衔接 | 第一镜接上一条成片的末帧并接着动；这条的末态写了；情绪接得上切点表 | agent |
| 6 表演 | 不一镜一句；说话的人有事做；听的人有反应和触发；不夸张；不大起大落；每镜对得上表演表 | agent |
| 7 节奏 | 台词共几秒、没台词最长几秒、几句的画面给了听的人、双人或环境 | 脚本出数，agent 抄 |
| 8 写法 | 六段、禁写词、字符数、每张图的用于和不采用、首次出场顺序 | 脚本 |

每道 agent 要看的：

**1 台词**

- 脚本比花括号里的字和方案的台词清单：逐字、顺序、句数。
- 每句前面写的说话人对不对。
- 画外的句子是有意的吗：分镜表的「画面给谁」里没有说话人。写了声音从画哪一侧传来吗。
- 没验证过的整句画外，在参数段的「未验证」里列出来。

**2 说法和声音**

- 每句的说法只有一两项，和表演表的「台词怎么说」一样。
- 台词后面只接别人的反应。
- 每个声音指得出来源。
- 【总述】和【贯穿要求】各有一遍无音乐；【贯穿要求】里说法列全。
- 写了语言；写了不要字幕。
- 【贯穿要求】里每人的音色，和方案的声音设定是同一句。

**3 空间**

- 脚本比了明说的左右和亮的是哪半边。没明说的地方自己逐镜对：`check.py dock3` 打印的那一行，和这一镜写的一样吗。
- 逐镜对主光：这个位置用的是不是站位表里那盏灯；人走了以后主光换了没有。
- 镜头行写的机位高度和焦段，和机位表一样。
- 左右没有写成人物自己的。反打镜没有描写镜头身后的东西。
- 写到的每样东西、每盏灯都在俯视图里。

**4 动作**

- 够得着吗，路上有没有挡着的东西。
- 每只手里是什么，逐镜跟一遍。
- 这个景别看得见吗：手、后景的人、要读的字。
- 一镜里的主要变化只有一个。

**5 衔接**

- 接上一条时，对的是上一条**成片**的末帧，不是上一条的 Prompt。参数段的「接上一条」写了"已对"和结果。
- 第一镜从末帧那一刻正在做的事的下一步开始，不重演上一拍。
- 最后一镜写了结束时每人的位置、姿态、情绪、手里的东西，和切点表的接缝状态一样。

**6 表演**

逐句过，和停靠时的逐句核对表一样看五样：

1. 不是说完一句切一镜。
2. 说话的人边做边说，身上有一个看得见的动作。
3. 每句有人接，反应看得见、有触发。
4. 没有夸张：笑、反应、群体的反应都有上限。
5. 没有大起大落：同一个人跨镜是渐变的，切点上不换脸。

再对一遍：每镜的表演是表演表里那几行，没有多出来的，也没有漏掉的。

**7 节奏**

- 把脚本打印的那句原样抄进这一行，后面再写自己的话。不自己算。
- 没台词最长的那一段，写一句在发生什么。

**8 写法**

- 脚本全过就写"过"加字符数。

## 怎么记

记在场记录的「QA」里，每条 clip 只留现行这一版：

```
### clip01 · Prompt v1
- 1 台词 · 过 · 13 句逐字，说话人都在画里
- 2 说法和声音 · 改了 · 镜 4 去掉一处"顿一拍"
- 3 空间 · 过 · 4 镜的左右和主光都和脚本算的一样
- 4 动作 · 改了 · 镜 2 水瓶换到画左那只手
- 5 衔接 · 过 · 接 #100 末帧
- 6 表演 · 过 · 13 句都有动作、有人接，没有夸张
- 7 节奏 · 过 · 台词 21.4 秒；没台词最长 2 秒；3 句的画面给了听的人、双人或环境。开头 2 秒是 Theo 坐下
- 8 写法 · 过 · 6200 字符
```

- 一道一行：`- 序号 名字 · 过或改了 · 说明`。
- 说明必填。"过"后面写查到的事实，不写"已检查"。
- "改了"后面写改了哪一镜的什么。
- Prompt 换版，整段换掉，标题里的版本号跟着改。旧版的 QA 不留。
- 一行超过 80 字，脚本会提示。

## 停靠时的检查

三次停靠各跑自己的 `check.py dock1 / dock2 / dock3`，再加 agent 的核对表：

| 停靠 | 核对表 |
|---|---|
| 第一次 | 不用表。台词清单和单场剧本逐字对一遍，写一句结果 |
| 第二次 | 逐句：说话的人在做什么、听的人怎么接、问题 |
| 第三次 | 逐镜：镜、句、说话的人在做什么、听的人怎么接、看得见吗 |

核对表贴在回复里，不写进方案。

## 检查判不了的

- 表演好不好、镜头好不好看，脚本和 QA 都判不了，只能查有没有按规矩写。
- 模型把一个词演偏，写之前拦不住。新写法先用单个镜头跑一轮。
