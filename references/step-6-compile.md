# 第 6 步 · 编译和 QA

方案五段都确认了才编。一次一条 clip：这条交了，再动下一条。

## 做法

1. **接上一条成片时，先对末帧。** 看上一条成片的最后一帧：每人在画左还是画右、姿态、手里的东西、穿着，和切点表的接缝状态一样吗。不一样先改方案（以成片为准），再编。结果写进参数段的「接上一条」：已对，一致；或已对，改了什么。
2. **从方案抄，不新编。** Prompt 的每一句指得回方案的某一格，或 `current-style.md` 的某一条。编的时候发现方案缺东西：回方案补，再编。
3. **左右和光照脚本算的写。** `check.py dock3` 对每一镜打印了从画左到画右是谁、每张脸怎么看见、主光亮的是哪半边、身后是什么。照它写，不自己推。
4. **按六段写。** 格式见 `templates/prompt.md`。
5. 跑 `check.py prompt`，不过就改。
6. **做 QA 八道**（`qa.md`），记进场记录，跑 `check.py qa`。
7. **交 Prompt。**

## 六段

| 段 | 写什么 | 从哪抄 |
|---|---|---|
| 【素材绑定】 | 每张图一行：用于谁的什么，不采用什么 | 参考图清单 |
| 【总述】 | 一句：谁、在哪、发生什么。再一句声音 | 目的、节拍表 |
| 【画面基调】 | 现行写法；这场的灯和人怎么对上；身后是什么 | 第 2 段、俯视图、站位表 |
| 【起始状态】 | 每人一句：画左还是画右、挨着什么、坐或站、脸朝哪、看谁、手里有什么 | 站位表的「起」，或切点表的接缝状态；左右按第一镜的机位 |
| 【分镜时间线】 | 每镜三样：镜头行、光、表演和台词 | 分镜表、表演表 |
| 【贯穿要求】 | 保持一致；空间与机位；表演约束；画面基调；声音 | 第 2–4 段、情绪线 |

**【素材绑定】**

- 一行只定义一个主体。人物按首次出场顺序，服装跟在人后面。
- 图够准时只指代，不复述图里的画面。图里看不出但要守的写在这里：年龄、身高关系。
- 两个人以上，加一句：几个人的外貌、服装、动作和台词不互相交换。
- 穿的和图不一样，分两种：
  - 图里有、这条从头到尾不穿的衣服：素材行点名写不采用图里的哪件；有这个人的每一镜都写当下穿的是什么（#10、#11）。
  - 这条里脱下、敞开、卷起袖子：素材行不写不采用，写「穿着按每一镜的文字」；【起始状态】写开场穿的是什么；有这个人的每一镜都写当下的样子；【贯穿要求】写之后一直怎样。这一种还没有成片核过，用了就列进「未验证」。
- 接上一条成片时，末帧图只管镜头 1 的开头，写明其他镜头不参考它。

**【总述】**

- 不写时长、画幅、分辨率。这些在生成页面里设。
- 声音一句是无音乐的第一遍：没有音乐，只有台词和写到的动作声。

**【起始状态】**

- 接上一条时，以上一条**成片**的末帧为准，不以上一条的 Prompt 为准。
- 这里的画左、画右按第一镜的机位写。

**【贯穿要求】**五样各写什么：

- 保持一致：脸、发型、服装和哪张图一致；东西的归属和状态；几个人。
- 空间与机位：轴线一句，谁在画左谁在画右；平视、轻微手持；这条里的推、拉、摇各在哪一镜。
- 表演约束：情绪线一句；上限的具体样子；不说话的人自然合着嘴，只用眼神和表情回应；说话的人边做边说；表情跨镜接着走；人物为正常人眼；动作正常速度。
- 画面基调：人物光的短句（见 `current-style.md`）；全条同一种灯光、同一个颜色；景深。
- 声音：人声的远近；每人的音色；只生成台词和写到的动作声；除了写出的 N 句台词没有人说别的话；无音乐的第二遍，说法列全；不要字幕。

## 一镜怎么排

```
镜头1（0-5秒）：近景，机位和 Theo 的眼睛同高，平视，中长焦，轻微手持，跟着 Theo 的上半身，晃动很小。Theo 在画面中间偏左，看着画右外的采访者。
光：Theo 的主光是画右那两根竖着的长条灯，……（句式见 current-style.md）
整体情绪从讲事的平静转为压着的笑。Theo 一边把搭在腿上的手抬起来比一下，一边用英语、讲事的口气，最后三个词前顿一拍、眼睛往下落一下再抬回来、嘴角微微上扬地说：{First time I saw Rhett on set, he was naked.} Rhett 在听，嘴角一侧先动。<皮沙发轻轻吱一声>
```

- **第一行**：景别；机位的高度和焦段，照机位表抄；运镜（方式、跟谁、起点和终点或晃动多大）；谁在画面哪、看谁。中长焦和长焦要写出来。
- **第二行**「光：」：这一镜每张脸一句。同一机位、人没动，写「同镜头 N」。
- **第三行起**：表演和台词，按发生的先后写。
- **每条的最后一镜**，末尾加一句结束时的样子：每人在哪、什么姿态、什么情绪、手里有什么。照切点表的接缝状态写。

## 写台词

- 台词放在花括号里，逐字。
- **说话人的表演和说法写在台词前面。** 台词后面只接别人的反应。
- **台词后面不回头提台词里的词。** 不写"说到某某时……"接在台词后面，容易出字幕。
- 说话人前写语言。口音用户说了才写。
- 一次只有一个人开口。
- **写成"一边……一边说"**，不写成先做完动作再开口（#52）。一件持续的事可以管几句。
- **说法只写这句有戏的一两项**，照表演表的「台词怎么说」抄。写满了成片一句一停（#52）。
- 不写逐句的起止秒。台词按先后写在所属的镜头里。
- 画外的台词：写谁的声音、从画哪一侧传来；画里的人照常写反应。
- 听的人每镜只写反应。"自然合着嘴"在【贯穿要求】里写一次，不逐句写。

## 写表演

- 情绪有转折的镜头才写「整体情绪从 A 转为 B」，其余镜头只写表现。
- 有触发的反应先写触发，再写反应："看到他把笔放下，……"。
- 触发是台词里的某个词时，不复述那个词：反应直接接在那句台词后面，靠先后表达。
- 几个动作写明先后："先……再……"。
- 一次转折两到四个表现，照表演表抄，不加。

## 写镜头

- 时间用整数秒，首尾相接：`镜头2（5-9秒）`。
- 运镜写跟谁、起点、终点。手持写跟拍对象和晃动程度。
- 接法照分镜表写在镜头行开头，如「硬切」。每条的第一镜不写接法；接上一条末帧时写"开头的画面和 @末帧图 一样"。
- 音效用尖括号写具体的声音。人名不用尖括号。
- 方位一律画左、画右，同时写挨着什么。每一镜的左右照脚本算的写；反打镜尤其不要凭感觉。
- 反打镜：只写画面里有什么；镜头身后的东西只留一句方向句。

## 有成片证据的写法

| 写法 | 证据 |
|---|---|
| 地标写相对镜头的位置：朝镜头走来、背对镜头走远、门在画右深处 | #6 |
| 轻松的戏不写停住、盯住、慢转头，成片像惊悚 | #7 |
| 手里的东西写哪只手、怎么握，另一只手在做什么 | #8 |
| 说法里不写"快"，台词会挤成一团 | #8 |
| 反打镜不描写镜头身后东西的样子，只留一句方向句 | #9 |
| 接末帧的第一镜接着动：从末帧那一刻正在做的事的下一步开始 | #9、#56 |
| 一句台词不跨镜；后半句不放画外 | #10 |
| 图里有、这条不穿的衣服：素材行点名写不采用哪件，每镜写当下穿的是什么 | #10、#11 |
| 强烈情绪词会让眼睛发光：用常规词，写「人物为正常人眼」 | 官方 |
| 参考图分辨率不超过输出分辨率 | 官方 |

更多的在 `phrase-ledger.md`。没验证过的写法在参数段的「未验证」里列出来，成片回来看。

## 不做的

- 不自动加画质包和通用的负向约束。
- 不为了字数删表演。超过 15000 字符：先删重复和复述，同机位的光写「同镜头 N」；还超就告诉用户，这是可以带着去问的第二件事。
- 不加方案里没有的镜头、动作、台词。
- 不写"同上一条""见 clip01"。每条 Prompt 六段都自己写全：模型看不到别的条。

## 版本和交付

- Prompt 从 v1 起，每交一版加一。文件只留现行版。
- 参数段写：方案版本、时长、画幅、上传顺序、接哪条成片的末帧和对过的结果、未验证的写法。参数段不贴给模型。
- 交付时回复里给：Prompt 正文全文；上传顺序；QA 八行；未验证的写法。
- 场记录的现行表更新这条的 Prompt 版本。

## 过关

- `check.py prompt` 过：六段齐；台词和方案逐字相同；镜头数和时间同方案；禁写词为零；15000 字符内；引用的图都在清单里；总述里没有时长和画幅；参数段的时长等于分镜的末秒；【贯穿要求】里有"不说话的人自然合着嘴"；明说的左右和亮面与俯视图算的一样。
- `check.py qa` 过：八道都有结论。
