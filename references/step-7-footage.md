# 第 7 步 · 成片回来

## 做法

1. **量。** 跑 `measure_clip.py`，再自己看拼图。
2. **记账。** 场记录的「成片」加一行：编号、clip 和 Prompt 版本、用户的原话、实测一行。
3. **判层。** 用户的话和自己看到的，逐条判：落在哪一层、哪几镜。
4. **定保底。** 这条 clip 目前最好的成片是哪条。
5. **改。** 从小处改起，一次只改一处，只动点到的地方。
6. **重查。** 跑受影响的检查，重做 QA，Prompt 版本加一。
7. **记写法。** 这次验证了什么、否掉了什么，记进写法账。

## 量成片

```bash
python3 scripts/measure_clip.py <成片> --prompt <Prompt>
python3 scripts/measure_clip.py <成片> --prompt <Prompt> --last-frame <存到哪.png>
```

要 ffmpeg。它给出：

| 量什么 | 怎么用 |
|---|---|
| 切点和每镜时长，和 Prompt 的镜头时间并排 | 多切、少切、差得多的镜，是「Prompt 某句」或「镜头」层的线索 |
| 有声几秒、开头结尾静音、最长静音在哪 | "拖、句子之间有空"先看这里 |
| 语速：这条的词数 ÷ 有声秒数 | 是语速的下限。和方案的语速差得多，回方案改语速 |
| 每镜一帧，拼成一张图 | 自己看图，见下面 |
| 每镜动没动 | "静"的镜，对一下是不是有人站着不动地说 |
| 相邻两镜变没变 | "平"的切点，对一下是不是换了镜等于没换 |
| 末帧（`--last-frame`） | 给下一条当参考图；编下一条前拿它对站位和左右 |
| 一行摘要 | 抄进成片账的实测 |

**看拼图**，逐镜对五样，和方案不一样的列出来：

1. 谁在画左、谁在画右。
2. 站位和姿态。
3. 主光从哪边来，亮的是哪半边脸。
4. 身后是什么，颜色对不对。
5. 穿的、手里拿的。

- 脚本的切点是估的，差一两个算正常，要紧的地方自己看图。
- 有声的秒数含动作声，所以算出来的语速是下限。
- **声音以用户为准。** 语气、音色、说话的节奏 agent 听不见，不下"没问题"的判断。

## 记账

```
- #101 · clip01 v1 · 否 · "镜 3 笑大了" · 切点 4/4 对上，有声 21 秒 · Prompt 镜 3 一句 · 改镜 3 的上限句
```

编号在项目里连着编，接上一条成片的号。

## 判层

| 层 | 怎么认 | 回到哪 |
|---|---|---|
| 抽卡 | 别处都对，只有一处偶发：手指、口型、一个物件 | 同一版重抽一次再判 |
| Prompt 某句 | 方案写对了，成片没照做或做偏了。指得出是哪一句 | 改那一句 |
| 镜头 | 切得碎、画面给错了人、这个景别或机位看不见写的东西 | 第 5 步 |
| 空间 | 左右反了、站位或主光不对、东西换了手 | 第 4 步 |
| 表演 | 夸张、平、干站着说、听的人没反应 | 第 3 步那一行 |
| 定调 | 色调、背景、声音的样子不对 | 第 2 步，或现行写法 |
| 解释 | 这场讲的东西不对、戏给错了人 | 第 1 步，下游全部重看 |
| 素材 | 脸、服装、场景图本身的问题 | 换图，改参考图清单 |

- 先判小的：抽卡 → Prompt 某句 → 方案。能改一句解决的不回方案。
- 判不准就告诉用户拿不准在哪两层之间，不硬判。

## 常见现象

| 现象 | 多半在 | 先查 | 证据 |
|---|---|---|---|
| 换脸、换衣，图里不穿的衣服被穿上 | 素材、Prompt | 素材行是否一行一个主体、点名了不采用；每镜是否写了当下穿什么 | #10、#11 |
| 先出场的人被别的角色顶替 | 素材 | 上传顺序是不是首次出场顺序 | 官方 |
| 参考图里不要的东西被照样画出来：标志、挂着的东西 | 素材 | 这样东西是不是在图里。文字写"空着""不参考"拦不住，换图或改图 | #20、#51、#52、#53、#56 |
| 切镜后人物换边，东西跑到另一侧 | 空间 | 左右是不是写成了人物或东西自己的；俯视图和机位对不对 | #8、#12 |
| 人物走反方向 | 空间、Prompt | 地标有没有写相对镜头的位置 | #6 |
| 反打镜被拍成场景图的视角 | 镜头 | 反打机位在不在图的视角里；有没有描写镜头身后 | #9、#42、#47 |
| 人物背光、不好看 | 空间、镜头 | 主光是不是侧前方的灯；机位是不是在暗面一侧 | #51、#52 |
| 背景纯黑 | 定调、Prompt | 有没有把背景写暗；有没有写身后具体是什么；反打镜写了吗 | #53，和它前一轮没编号的成片 |
| 肤色发黄 | 素材、定调 | 几张场景图色调一致吗；先换图 | #54 |
| 一条里两套色调，没图的地方发黑发绿 | 素材、定调 | 这块地方有没有场景图；分区写光有没有写同色 | #55、#56 |
| 轻松的戏像惊悚 | 表演、Prompt | 有没有停住、盯住、慢转头、压低声音 | #7 |
| 笑大了、表情夸张 | 表演、Prompt | 情绪词后面有没有跟具体的表现；上限有没有写成具体的样子 | #48、#50 |
| 姿态拘谨、表情拘束 | 表演 | 是否照抄了剧本的姿态词；有没有写往前倾、手放腿上；笑是不是写成"合着嘴的笑" | #52 |
| 没有交流，各说各的 | 表演、镜头 | 人物看不看对方；问的人和答的人有没有同框 | #51 |
| 一句一停，接话的人等着 | Prompt | 说法是不是写满了；是不是写成先做动作再开口 | #52 |
| 台词挤成一团 | Prompt | 说法里有没有"快" | #8 |
| 同一个人的声音变了 | Prompt | 他的音色是不是和前几条同一句 | #45 |
| 听的人替说话的人开了口 | 镜头 | 是不是一句跨了两镜、后半句画外 | #10 |
| 切得碎、太快 | 镜头 | 两三秒的插镜是不是多了 | #51 |
| 画面一直没有变化 | 镜头 | 相邻两镜是不是换了等于没换；景别、机位、画面给谁是不是老一个样，看 `check.py dock3` 的三张总览 | #5 |
| 拖，句子之间有空 | 镜头 | 没台词的段和单镜的余量。时间段模型会照着演 | #1、#51 |
| 下一条开头像定格 | Prompt | 第一镜是不是把上一条最后一拍又演了一遍 | 没有成片记录 |
| 动作被跳过、演得赶 | 镜头 | 这一镜的事是不是多于一件；时长够不够 | 官方 |
| 出了音乐 | Prompt | 说法列全了吗；首尾各一遍了吗 | 官方 |
| 出了字幕 | Prompt | 台词后面有没有回头提台词；写了不要字幕吗 | 官方 |
| 多出一句话、多出人声 | Prompt | 有没有笼统的人声描述；写了"除了写出的 N 句"吗 | 用户 11-11，没确认是哪条 |
| 眼睛发光 | Prompt | 有没有强烈情绪词 | 官方 |

## 保底

- 场记录的现行表写明每条 clip 的保底成片和它的 Prompt 版本。
- 新版本赢过保底才换。
- 保底的 Prompt 不是现行版时，另存一份 `<场>-clipNN.prompt.保底.md`。换保底时覆盖它。
- **同一条改两轮没赢过保底，停下来问用户**，不再往下叠版本。

## 改

| 改的是 | 回到 | 跟着重做 | 不动 |
|---|---|---|---|
| 一句台词 | 单场剧本、台词清单、表演表那一行 | 那一镜的预算和 Prompt | 其余 |
| 场景图或布景 | 参考图清单、第 4 步 | 俯视图、各镜机位和光；Prompt 的素材、基调、起始状态 | 解释、表演表 |
| 服装图 | 参考图清单 | Prompt 的素材绑定、贯穿要求 | 其余 |
| 某一拍的表演 | 表演表那一行 | Prompt 那一镜 | 其余 |
| 某一镜、机位或切点 | 第 5 步 | Prompt 的分镜时间线 | 前三步 |
| 光、基调、声音的写法 | 现行写法或导演偏好 | Prompt 对应的句子 | 方案 |
| 谁的戏、人物状态 | 第 1 步 | 下游全部重看 | — |

- 一次只改一处。两处一起改，成片好了坏了都不知道是哪一处。
- 只改点到的地方，别的镜不动。
- 新的光线、表演、运镜写法，先用单个镜头跑一轮，确认了再放进整条。
- 用户手改了 Prompt：以用户的为准，差异回写方案。
- 用户否过的事不再当选项问。动手前先看场记录的「决定」。
- 每次改，场记录的「决定」记一行：日期、在哪一步、用户原话、改了什么。

## 记写法

- **写法账**：成片证明好用的写法、被否掉的写法，各记一行进 `phrase-ledger.md`：写法、成片编号、结果、样本几条。这是事实，直接记，不用等点头。
- 一两条成片的结果是方向，不是定论。照实写样本有多少。
- **固定要求候选**：用户说"以后都这样"的话，记进场记录的「固定要求候选」。每场定版后给用户看一遍，点头的写进 `current-style.md`；只属于这个项目的写进项目的 `导演偏好.md`。写进去的从候选里删掉，文件末尾记一行日期。

## 过关

- 成片账记了：编号、版本、用户原话、实测。
- 每条意见判了层，指到了镜。
- 现行表里有保底。
- 这一轮只改了一处。
- 写法账记了这次的结果。
