# 写法账

一种写法，成片把它演成了什么。拿不准一种写法好不好用，先查这里。

- 一行一条：写法、成片结果、证据、样本几条。
- 证据写成片编号（#数字），或用户哪天说的话。#6–#13 是 OFFSET 早先几集，#37–#50 是 OFFSET EP08，#51 起是 OFFSET EP09；#1–#5、#14–#25 是别的项目。#26–#36、#41 没有记录。
- 成片回来，验证过的和否掉的各记一行，直接记，不用等点头。
- 一两条成片的结果是方向，不是定论。样本栏照实写；一条成片同时改了几样的，写"多变量"。
- 固定要求写在 `current-style.md`。这里记的是为什么，和试过什么。
- 别的项目（#1–#5、#14–#25）只收了少数几条；特效的写法（魔法、变身）没有收。
