怎么填（用的时候删掉这一段；方括号是要填的地方）：

- 每段标题后面的状态：`待确认`；用户确认后改成 `已确认 [日期]`；用户说一次到 Prompt 时写 `免停靠 [日期]`。
- 每次交给用户看之前，版本加一。为什么改，记在场记录的「决定」里，这里不写。
- 放行：用户点名要用的禁写词或非默认手法，写上词和用户原话。
- 表里的格子直接写成能进 Prompt 的句子。一格超过 120 字考虑拆行。
- 表演表「句」栏：说话的人填句号；听的人填「听 3」或「听 3–5」；没台词填「—」。
- 俯视图的坐标按场景图的视角：x 从画左 0 到画右 10，y 从近 0 到远 10。类只写固定物、灯、点。
- 站位表「点」栏写俯视图里的点；「主光」写俯视图里的灯。有人离场：给出口标一个点，他那一行的姿态以「离场」开头。
- 机位表「高度」写和谁的眼睛同高；「焦段」写广角、中焦、中长焦、长焦之一；「拍什么」写这个机位拍到了别的机位拍不到的什么。
- 分镜表「时间」写 `0-5`；「机位」写机位表里的字母；「运镜」写 `方式｜跟谁｜起点 → 终点`，不动写「构图不变」；「表演表的行」写 `拍-人物`。
- 每栏怎么填，看对应那一步的文件。
